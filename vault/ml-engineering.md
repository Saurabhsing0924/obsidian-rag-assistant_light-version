# ML Engineering

Machine learning engineering is the discipline of taking models from research notebooks to production systems. It sits at the intersection of software engineering and data science.

## Core Responsibilities

ML engineers own the full lifecycle: data ingestion, feature engineering, model training, serving, and monitoring. They build the infrastructure that makes models reliable at scale.

## Key Differences from Data Science

While data scientists focus on experimentation and model selection, ML engineers focus on reliability, latency, cost, and maintainability. A model that achieves 95% accuracy in a notebook but takes 30 seconds to respond in production is an ML engineering problem.

## Typical Stack

Common tools include Python, PyTorch or TensorFlow, Docker, Kubernetes, MLflow, and cloud providers like AWS SageMaker or GCP Vertex AI.
